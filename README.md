# Grok Flight

Браузерный авиасимулятор на [Three.js](https://threejs.org/) в одном HTML-файле.  
Город в духе Москвы, аэропорт с ИИ-трафиком, несколько ЛА, геймпад, звук и физика полёта.

## Запуск

1. Скачай `flight-sim-v3.html`
2. Открой в **Chrome** / **Firefox** / **Safari** (лучше через локальный сервер, но `file://` тоже работает)
3. Нажми **ВЗЛЕТАТЬ**

```bash
# опционально
npx serve .
# или
python3 -m http.server 8080
```

Мобильные: открой файл на телефоне, повернув экран горизонтально удобнее.

## Управление

| Действие | Клавиатура | Тач | Геймпад / RC |
|----------|------------|-----|--------------|
| Газ / тормоз | W / S (Ц / Ы) | полоска THR | калибруемая ось |
| Тангаж / крен | стрелки | левый стик | оси |
| Рысканье | A / D (Ф / В) | правый стик | ось |
| Закрылки / шасси | F / G | FLP / GEAR | — |
| Камера | C | CAM | — |
| Сброс на ВПП | R | RST | — |
| Огонь (F-16, Spitfire) | Space | FIRE | — |
| Чувствительность | + / − или слайдер | Sens | — |
| Калибровка геймпада | кнопка **GP** | GP | при подключении |

Самолёты: клавиши **1–6** или кнопки в меню.

## Возможности

- **6 ЛА**: Cessna, Citation Jet, F-16, Airbus A320, Spitfire, Robinson R22  
- Процедурный город (Москва: Кремль, Сити, Останкино, МГУ, река…)  
- Текстуры фасадов, шоссе, машины, ИИ-взлёты  
- Миникарта и точки интереса  
- Анимированные шасси и закрылки  
- Звук двигателя, ветер, сирена сваливания  
- Инверсионный след на высоте  
- Оценка посадки (S/A/B/C/D)  
- Достижения (localStorage)  
- Калибровка каналов геймпада / Radiomaster  
- Адаптивное качество для телефонов
